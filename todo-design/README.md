# To-Do: веб-приложение — дизайн и спецификация

Пакет для разработки (например, Codex). Здесь всё, что нужно, чтобы собрать интерфейс 1-в-1 с макетом.

```
todo-design/
├── README.md          ← этот файл: экраны, данные, поведение
├── styles.css         ← готовые стили (цвета, шрифты, компоненты)
├── tokens.json        ← дизайн-токены: цвета, шрифты, радиусы
├── screens/           ← статические HTML-макеты, открываются в браузере
│   ├── home.html              1. Главная (4 виджета)
│   ├── tasks-no-project.html  2. Внепроектные задачи
│   ├── projects.html          3. Проекты
│   ├── all-tasks.html         4. Все задачи (блок «Прокрастинация» раскрыт)
│   ├── task-card.html         5. Карточка задачи (просмотр)
│   ├── task-new.html          6. Новая задача
│   └── task-edit.html         7. Редактирование задачи (та же форма, заполнена)
└── screenshots/       ← PNG тех же экранов, 1440 px
```

Макеты статические: данные в них примерные, логика описана ниже. Ссылки между экранами уже расставлены.

## Инструкция для Codex (можно вставить как промпт)

> Сделай веб-приложение To-Do по макетам из папки `todo-design/`. Визуал повторяй по `screens/*.html` и `styles.css`. Названия классов и токены можно переиспользовать. Поведение и модель данных — по `README.md`. Язык интерфейса — русский. Адаптив: на ширине до 720 px боковое меню уходит наверх, формы становятся в одну колонку, виджеты главной — в одну колонку до 900 px.

## Модель данных

```ts
type Status = 'waiting' | 'in_progress' | 'done'   // Ожидает / В работе / Исполнено — ровно три

Task {
  id: string
  title: string                 // обязательно
  status: Status                // по умолчанию 'waiting'
  description: string           // текст или Markdown
  descriptionFormat: 'text' | 'markdown'
  parentId: string | null       // родительская задача → дерево любой глубины
  projectId: string | null      // null = внепроектная задача
  labels: string[]              // свободные метки, автодополнение из уже использованных
  dueDate: string | null        // ISO-дата, null = без даты
  createdAt: string
  history: { at: string, type: 'created'|'status_changed'|'due_changed'|'subtask_done'|..., data }[]
}
Project { id, name, description, color, createdAt }
```

«Просрочено» — это не статус, а вычисляемый признак: `dueDate < сегодня && status !== 'done'`.

## Общие элементы

- **Левое меню** (сверху вниз): логотип; кнопка «Новая задача»; **Главная** (домик); **Внепроектные задачи**; **Проекты**; **Все задачи**; ниже список проектов с цветными метками. Отдельного пункта «Прокрастинация» нет.
- **Статус в строке задачи** — иконка слева от названия, клик переключает по кругу Ожидает → В работе → Исполнено:
  - Ожидает — пустой серый круг;
  - В работе — синий круг, закрашенный наполовину;
  - Исполнено — зелёный круг с галочкой, название зачёркнуто и приглушено.
- **Даты**: «Сегодня» — синим, «Завтра» — обычным, просроченные — оранжевым (`--warn`), без срока — «Без даты». Формат `10 нояб.`.
- **Строка задачи** (один компонент для всех списков): [стрелка раскрытия в дереве] · [чекбокс выбора — только когда раскрыта «Прокрастинация»] · иконка статуса · название (ссылка на карточку) · метки · счётчик подзадач `1/2` · проект · срок.

### Блок «Прокрастинация» — у КАЖДОГО списка задач

Это не экран, а сворачиваемая опция в заголовке любого списка: виджеты главной, внепроектные задачи, задачи проекта, все задачи.

- Свёрнут: кнопка `⧗ Прокрастинация ›` в заголовке списка.
- Раскрыт (кнопка становится тёмной, стрелка вниз):
  - в каждой строке слева появляется квадратный чекбокс выбора;
  - под заголовком тёмная панель: чекбокс «выбрать все», «Выбрано: N», «Перенести на»: **Сегодня**, **Завтра**, **Через неделю**, **На дату…** (календарь), ✕ — свернуть и снять выбор;
  - кнопка переноса меняет `dueDate` у выбранных задач и пишет запись в `history`.
- Варианты, которые не имеют смысла, скрываются: в виджете «План на сегодня» нет кнопки «Сегодня».
- Выбор родительской задачи не выбирает подзадачи автоматически.

## Экраны и поведение

### 1. Главная — `home.html`, маршрут `/`
- Приветствие, дата, сводка «на сегодня N задач, M исполнены»; справа поле «Быстро добавить задачу на сегодня…» (Enter создаёт задачу со сроком «сегодня», статусом «Ожидает», без проекта).
- Сетка 2×2 из виджетов, у каждого свой блок «Прокрастинация»:
  - **слева вверху — «План на сегодня»**: задачи со сроком сегодня, прогресс «X из Y исполнено». На макете блок прокрастинации раскрыт.
  - **справа вверху — «Просрочено»**: задачи с прошедшим сроком, не исполненные, с чипом «N дн.» просрочки, сначала самые давние.
  - **слева внизу — «Задачи на завтра»**.
  - **справа внизу — «Все задачи»**: счётчики по статусам (Ожидает / В работе / Исполнено) и ближайшие задачи по сроку.
- Внизу каждого виджета ссылка на полный список (на экран «Все задачи» с нужным фильтром).

### 2. Внепроектные задачи — `tasks-no-project.html`, маршрут `/tasks/no-project`
- Только задачи с `projectId = null`.
- Вид: **Список** / **Дерево** (подзадачи вложены, раскрываются стрелкой).
- Панель фильтров: поиск по названию; срок (Все / Просрочено / Сегодня / Завтра / Неделя / Без даты, со счётчиками); статус (Все / Ожидает / В работе / Исполнено); сортировка (кнопка-иконка: по сроку ↑, по сроку ↓, по названию).
- Заголовок списка с кнопкой «Прокрастинация» (на макете свёрнута).
- Справа панель быстрого просмотра выбранной задачи: статус, проект, срок + «просрочено на N дней», метки, начало описания, кнопки «Открыть» (→ карточка) и «Редактировать» (→ форма). Границу между списком и панелью желательно сделать перетаскиваемой.

### 3. Проекты — `projects.html`, маршрут `/projects`, `/projects/:id`
- Слева плоский вертикальный список проектов с поиском и счётчиками задач.
- Справа выбранный проект: название, описание, «Изменить», счётчики (Ожидает / В работе / Исполнено / Просрочено).
- Список «Задачи · сначала новые» — **дерево** задач проекта по дате создания (новые сверху), у строки «создана дд.мм» и срок. В заголовке списка — «Прокрастинация» и «+ Задача в проект».
- «Создать новый проект» — форма: название (обязательно) и описание, «Сохранить / Отмена».

### 4. Все задачи — `all-tasks.html`, маршрут `/tasks`
- Абсолютно все задачи: проектные и внепроектные.
- Те же фильтры, что на экране 2, плюс фильтр по проекту (Все проекты / Без проекта / конкретный проект).
- В заголовке списка — счётчики по статусам и «Прокрастинация». **На макете блок раскрыт**: видны чекбоксы и панель переноса (выбрано 3).

### 5. Карточка задачи — `task-card.html`, маршрут `/tasks/:id`
- Хлебные крошки: Проекты › Проект › Задача (для внепроектной: Внепроектные задачи › Задача).
- Большой заголовок, чип статуса, чип «Просрочено на N дней» (если просрочена).
- **Кнопка «Редактировать»** → `/tasks/:id/edit`. Меню «…»: дублировать, удалить.
- «Сменить статус» — переключатель из трёх: Ожидает / В работе / Исполнено.
- Свойства: проект, срок (+ день недели), родительская задача (ссылкой), метки.
- Описание **отрендерено** (Markdown → HTML: жирный, курсив, заголовки, списки, `код`).
- Подзадачи: прогресс «X из Y исполнено», список строк, кнопка «+ Подзадача» (форма с заполненным родителем).
- Справа «История»: создание, смена статуса, перенос срока, исполнение подзадач.

### 6. Новая задача — `task-new.html`, маршрут `/tasks/new`
- **Название** — обязательно; без него «Создать» не срабатывает, показать ошибку «Введите название».
- **Статус** — переключатель из трёх, по умолчанию «Ожидает».
- **Описание** — «Текст / Markdown». В режиме Markdown поле делится: слева исходник, справа живой предпросмотр.
- **Родительская задача** — поле с поиском по задачам; пусто = без родителя.
- **Проект** — поле с поиском: при вводе список фильтруется, совпадение подсвечивается; ↑/↓/Enter выбирают, Esc закрывает. Если точного совпадения нет — пункт «+ Создать проект «…»». Пусто = внепроектная задача. (На макете список раскрыт.)
- **Сделать до** — дата, ✕ «без даты», быстрые кнопки: Сегодня / Завтра / Через неделю.
- **Метки** — ввод с автодополнением; Enter или запятая добавляют чип, × удаляет; ниже частые метки.
- Кнопки: «Отмена», «Создать задачу» (→ карточка новой задачи). Ctrl+Enter — сохранить.
- Открыта из проекта или из «+ Подзадача» → соответствующее поле уже заполнено.

### 7. Редактирование — `task-edit.html`, маршрут `/tasks/:id/edit`
- Та же форма, что и «Новая задача», **заполненная данными задачи** (включая статус).
- Кнопки: «Отмена» (→ карточка без сохранения), «Сохранить» (→ карточка), слева «Удалить задачу» (с подтверждением).

## Стиль

- Шрифты: Inter (текст), Manrope (заголовки), Google Fonts, кириллица есть.
- Цвета (`tokens.json`): фон `#F5F5F2`, карточки `#FFFFFF`, текст `#17171A`, вторичный `#5E5F66`, акцент `#3451D1`, просрочено `#B23F0B`, исполнено `#1D7A4C`, линии `#E5E4DF`.
- Радиусы: карточки 10 px, поля 7 px, кнопки 9 px. Высота кнопок и полей — 40–42 px.
- Иконки — линейные, 1.8 px (в макетах инлайн-SVG; в коде можно взять lucide).
