# Словарь SQLite

Все даты и время создания записываются как ISO-строки. Даты сроков не содержат времени; вычисление просрочки относится к местному календарному дню Москвы. Первичные ключи строк задач и проектов — случайные идентификаторы. Ссылки между задачами и проектами дополнительно проверяются в транзакции на принадлежность одному владельцу и проекту.

## users — пользователи

| Поле | Значение |
|---|---|
| id | Числовой первичный ключ пользователя. |
| username | Уникальный логин. |
| password_hash | Соль и результат scrypt, пароль в открытом виде не хранится. |
| created_at | UTC-время создания пользователя. |

## sessions — сеансы

| Поле | Значение |
|---|---|
| token_hash | SHA-256 случайного токена cookie; первичный ключ. |
| owner_id | Ссылка на владельца сеанса. |
| csrf | Случайный CSRF-токен сеанса. |
| expires_at | Время истечения в секундах Unix. |

## projects — проекты

| Поле | Значение |
|---|---|
| id | Случайный первичный ключ проекта. |
| owner_id | Владелец проекта. |
| name | Обязательное название. |
| description | Описание проекта. |
| color | Цвет вида `#RRGGBB`. |
| created_at | UTC-время создания. |

## tasks — задачи

| Поле | Значение |
|---|---|
| id | Случайный первичный ключ задачи. |
| owner_id | Владелец задачи. |
| title | Обязательное название. |
| status | Один из `waiting`, `in_progress`, `done`. |
| description | Исходный текст описания. |
| description_format | `text` или `markdown`. |
| parent_id | Родительская задача или NULL; циклы запрещены. |
| project_id | Проект или NULL для внепроектной задачи. |
| labels | JSON-массив строк с метками. |
| due_date | Календарная ISO-дата или NULL. |
| created_at | UTC-время создания. |

## history — история задач

| Поле | Значение |
|---|---|
| id | Числовой первичный ключ записи. |
| owner_id | Владелец события. |
| task_id | Задача, к которой относится событие. |
| at | UTC-время события. |
| type | Тип события: создание, изменение, смена статуса/срока или выполнение подзадачи. |
| data | JSON с подробностями события, например прежним и новым сроком. |

При удалении задачи история удаляется вместе с ней. Для защиты от конкурентных изменений подтверждение удаления сравнивается с полным деревом внутри транзакции `BEGIN IMMEDIATE`; узлы удаляются от листьев к корню, чтобы не зависеть от ограничения глубины каскадов SQLite. Пакетный перенос предварительно проверяет все идентификаторы владельца и выполняется атомарно.

Дополнительные поля `projects.description_format` и `projects.labels` содержат формат описания (`text` или `markdown`) и JSON-массив меток. При запуске старой базы они добавляются без пересоздания таблицы с начальными значениями `text` и `[]`.

## project_colors — последние цвета проектов

| Поле | Значение |
|---|---|
| owner_id | Владелец персонального списка цветов, ссылка на пользователя. |
| color | Нормализованный цвет `#RRGGBB`; вместе с `owner_id` образует первичный ключ. |
| used_at | UTC-время последнего успешного сохранения проекта с этим цветом. |

Список ограничен двадцатью уникальными цветами каждого пользователя и обновляется в транзакции сохранения проекта. Отмена формы на него не влияет. Событие `edited` содержит имена фактически изменённых полей задачи. Старые записи `updated` сохраняются в базе; API скрывает только пустые дубли непосредственно после смены статуса или срока в пределах секунды.
