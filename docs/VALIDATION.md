- 7 автоматических API-тестов прошли в виртуальном окружении проекта. Проверены изоляция пользователей, CSRF, капча и ограничение попыток, связи и циклы, атомарность переноса, подтверждение удаления, Markdown, история и описания столбцов SQLite.
- Независимый обзор и 54 дополнительные проверки API не нашли новых дефектов после исправлений. В том числе проверены параллельный перебор логинов, смешанный пакет своих/чужих задач, работа с чужими проектами/историей и удаление цепочки из 1100 узлов.
- 21 сценарий headless Chromium прошёл на собранном Docker-образе: семь экранов, ввод и правка, Markdown, проекты, клавиатурные комбобоксы с одинаковыми названиями задач, дерево, статусы, отмена/подтверждение переноса и удаления, мобильный выход. Ошибок JavaScript нет.
- На главной нет прокрутки всей страницы при 1440×900, 1920×1080 и 2560×1440; длинные списки прокручиваются внутри виджетов. Проверена мобильная ширина 390 px.
- SQLite сохранила данные после полного удаления и создания тестового Compose-контейнера с тем же томом.
- Рабочий контейнер `todo-todo-1` запущен от UID 10001 и имеет статус healthy. Адрес: http://127.0.0.1:18080. Данные: постоянный том `todo_todo_data`.
- Созданы `test1`, `test2`, `test3`; вход, пустые личные списки и выход проверены для каждой учётной записи. Пароли находятся в исключённом из Git файле `secrets/test-users.json` и переданы пользователю в чате.

## Воспроизведение

Команды приведены в README. `scripts/check-browser.ps1` создаёт отдельный контейнер, использует tmpfs для тестовой БД и удаляет контейнер в `finally`. Отчёт, снимки и лог последнего прогона: `artifacts/browser-final/`. Дополнительные журналы: `artifacts/docker-smoke.log`, `artifacts/docker-persistence.log`.

## Состояние окружения

Docker доступен через фоновое выполнение с расширенными правами; ограниченная среда Windows не имеет доступа к Docker pipe. Для одноконтейнерного приложения используется существующий `bridge`, поскольку свободные подсети для новых сетей Docker на компьютере закончились. Чужие контейнеры, сети и тома не изменялись.

Все временные Docker-контейнеры, сети и тестовый том этой задачи удалены, отсутствие проверено. Оставлены только рабочий контейнер и постоянный том для пользователя. Образы сохранены как результаты сборки, а не работающие тестовые окружения.

При первоначальной установке исполнитель ошибочно обновил пакеты пользовательского Python. Подтверждённые журналом прежние версии восстановлены. Добавленные Markdown 3.11.3, bleach 6.4.0 и webencodings 0.6.1 оставлены, поскольку прежнее состояние для них достоверно не зафиксировано. Подробности: `artifacts/python-environment-recovery.log`. Дальнейшая установка и все проверки выполнялись в `.venv` / `.qa-venv` либо Docker. Существующие несовместимости пользовательского окружения не исправлялись в рамках приложения.

Публикация в GitHub не выполнялась; удалённые репозитории не настраивались. CloudPub пока не настраивался: по исходной постановке это следующий пользовательский этап. Проверка туннеля HTTPS не входит в выполненную локальную приёмку.
