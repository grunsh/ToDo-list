# Проверка исправлений редактора проекта

- 10 API-тестов: `pytest -q --basetemp artifacts/final-api-20261112`.
- Независимая проверка: 31 дополнительная проверка истории, миграции, изоляции пользователей, Markdown, CSRF и порядка последних цветов.
- `scripts/check-browser.ps1`: 21 прежний сценарий и 6 групп проверок `browser_annotations.py`; Chromium headless, без управления рабочим столом. Проверены ширина формы, загруженные шрифты Inter/Manrope, Markdown, метки, RGB/HEX, отмена, восстановление после неверного ввода, 20 цветов в два ряда, история и мобильный экран 390px. Ошибок JavaScript нет.
- `node --check app/static/app.js` и `git diff --check` прошли.
- На копии рабочей SQLite-базы миграция выполнена трижды: исходные значения всех столбцов таблиц users, sessions, projects, tasks, history совпали полностью; integrity_check и foreign_key_check прошли.
- Перед рабочим обновлением сервер остановлен и создана отдельная резервная копия. После запуска проверенного образа сохранность исходных строк подтверждена сравнением базы до/после. Проверка `/health` успешна.
- Все одноразовые контейнеры удалены; временных сетей и томов нет. Рабочий контейнер и постоянный том сохранены. Логи, снимки браузера и резервные копии находятся в игнорируемом каталоге artifacts и не публикуются.

Для повторения браузерной проверки создайте `.qa-venv` по README и запустите `scripts/check-browser.ps1`. При использовании уже установленного Chromium задайте `TODO_QA_CHROMIUM` его абсолютным путём.
